<h1 align="center">Desktop Pets</h1>

<p align="center">
  <b>Lightweight, interactive pixel-art companions for your Windows desktop.</b>
</p>

---

Desktop Pets lets cute animated virtual pets (Bunny, Gorgon, Werewolf) roam along the bottom of your screen while you work or game. It features full click-through transparency (so it never blocks your clicks), cursor interaction, and system tray controls.

---

## 🚀 Installation

### Option 1: Via Windows Package Manager (Winget)
```bash
winget install KunalJangid.DesktopPets
```

### Option 2: 1-Click Installer (GitHub Releases)
1. Go to **[Releases](https://github.com/kunal-jangid/Creature/releases)**.
2. Download and run **`DesktopPets-Setup-vX.X.X.exe`**.

### Option 3: Portable ZIP
Download **`DesktopPets-win-x64-vX.X.X.zip`** from [Releases](https://github.com/kunal-jangid/Creature/releases), extract it anywhere, and launch **`DesktopPets.exe`**.

> **Note on Windows SmartScreen:** On first run, Windows may show an *"Unrecognized app"* prompt. Click **More info** $\rightarrow$ **Run anyway** to proceed.

---

## 🕹️ Controls

Right-click the **Desktop Pets** icon in your Windows System Tray (near the taskbar clock) to:
- **Adopt Pets**: Spawn up to 4 pets on your screen (Bunny, Gorgon, Werewolf).
- **Rename & Labels**: Give each pet a custom name and toggle hover tags.
- **Resize**: Scale pets from 1.0x (32px) up to 4.0x (128px).
- **Start with Windows**: Toggle automatic startup on boot.
- **Pause**: Freeze pets in place.
